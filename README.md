# Vênus por Thaianne — GitHub Pages

Estrutura recomendada no repositório (sem pasta `assets`):

- index.html
- styles.css
- app.js
- logo-venus.png
- CNAME
- termos.html
- politica-de-privacidade.html

Esta versão mantém o site bilíngue, carrinho, cupons e checkout e acrescenta:
- navegação com hover colorido e microanimação;
- hero mais dinâmico com logo oficial e elementos celestiais;
- cards e etapas com movimento no hover;
- animações suaves ao rolar a página;
- seção Contact Us com WhatsApp e e-mail;
- footer em vinho/rosé em vez de preto puro;
- botão voltar ao topo maior e animado.

IMPORTANTE: antes de publicar, troque o número de WhatsApp e o e-mail de contato pelos dados reais. Configure também os links de pagamento em `app.js`.
